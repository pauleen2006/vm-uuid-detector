# IBM ILMT — VM Duplicate UUID Detector

An interactive diagnostics, query generation, and remediation tool for IBM License Metric Tool (ILMT) duplicate VM UUID scenarios across Microsoft Hyper-V, VMware vCenter/ESXi, KVM, Nutanix AHV, and Microsoft Azure.

## Files Included

- **VM-UUID-Detector_LIVE.html / index.html** — Complete standalone web application with built-in parsers, hypervisor query generators, fix guides, and export tools.
- **VM-UUID-Detector.html** — Base tool build.
- **hyperv-uuid-checker.ps1** — Companion PowerShell collection script for Hyper-V hosts.

## Quick Start

Open VM-UUID-Detector_LIVE.html (or index.html) in any modern web browser.
